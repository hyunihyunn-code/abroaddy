# 어브로디 (Abroaddy)

> 나만의 든든한 해외 지출 버디 — 해외에 머무는 동안 쓴 돈을 캡처 한 장으로 정리하고, 오늘·이번 달 쓸 수 있는 돈을 알려주는 여행 가계부.

[`어브로디_PRD_v2_최종.md`](어브로디_PRD_v2_최종.md) 기반으로 만든 **모바일/웹 앱 프로토타입**입니다. 데스크톱에서는 앱 캔버스가 가운데 정렬되고, 모바일에서는 전체 화면으로 열립니다. PWA라서 홈 화면에 설치할 수 있어요.

## 실행

정적 파일이라 서버만 있으면 됩니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 열기
```

## 화면 · 기능

- **온보딩** — 웰컴 → 프로젝트 생성 → 완료 (F13 / S1–S3)
- **홈** — 오늘·이번 달 쓸 수 있는 돈, 사전예약/현지 2봉투, 현금 잔액, 보증금, 착지 예측 (F2 / S4)
- **가계부** — 월별 달력 + 1/N 정산 모드 (F7·F10 / S5)
- **지출 추가** — 결제내역 스캔 · 영수증 촬영 · 직접 작성 + 인식 실패 폴백 (F3 / S6·S7)
- **지출 상세/편집** — 통화·분류·결제수단·사전예약·반복지출·메모 (F3~F6·F8 / S8)
- **리포트** — 항목별·결제수단별·보증금·또래 비교·예산 변경 이력 (F9 / S10)
- **MY** — 적용 환율, 프로젝트 목록, 정산 계좌, 보낸 정산, 반복 지출, 내 카테고리 (S11)
- **정산 링크** — 앱 설치 없이 열리는 수신자 페이지 [`s.html`](s.html) (F7-4)

## 시연 데이터 (부록 16)

앱을 열면 3개 프로젝트가 담겨 있습니다.

| 프로젝트 | 특징 |
| --- | --- |
| 상하이 먹방 여행 (3일) | 일 단위 예산 · 또래 비교 활성 |
| 서현이와 덴마크 (153일) | 월 단위 예산 · 보증금 · 반복지출 · 표본 부족 |
| 유럽 한 바퀴 (14일) | 다국가 · 원화 강제 · 비교 제외 |

기록·정산·예산 변경은 브라우저 `localStorage`에 저장됩니다. **MY → 예시 데이터 다시 불러오기**로 초기화할 수 있어요.

## 디자인

- 은은한 밝은 그라데이션 배경 + 글래스모피즘, 금액 카드는 흰색 바탕
- 쿨블루 중심 · 포인트는 터콰이즈~블루퍼플 (블루 계열 유지)
- Pretendard, 금액은 tabular-nums


## 프로토타입 범위

PRD 부록 A(목업 vs 실제 구현) 기준으로, 환율은 고정 상수·스캔은 하드코딩 결과·정산 링크는 정적 페이지입니다. 실제 서비스에서는 환율 API, Claude 비전 스캔, 스냅샷 API, 서버 집계로 대체됩니다.
